# 纸箱报价系统

一款专业的移动端纸箱报价工具,帮助销售人员快速生成精准报价。

## 功能特性

### 📱 移动端优先设计
- 底部标签导航,操作便捷
- 触摸友好的交互体验
- 支持离线使用(PWA)

### 💰 智能报价计算
- **三大核心模块**:
  1. **报价模块**: 快速输入参数,自动计算成本和报价
  2. **模板管理**: 支持标准/半定制/全自定义三种模板类型
  3. **历史记录**: 完整的报价记录追溯和比价功能

### 🎯 核心功能

#### 1. 报价计算
- 客户信息管理(支持客户等级:普通/长期/大客户)
- 纸箱尺寸输入(支持内径/外径切换)
- 楞型选择(A/B/C/E/AB/BC楞)
- 用纸配置(面纸/里纸/芯纸克重)
- 工艺要求(印刷色数、特殊工艺)
- 自动计算成本拆解(纸料/损耗/工艺/利润/税费)

#### 2. 模板管理
- 预置3种标准模板(外箱/内盒/飞机盒)
- 支持创建自定义模板
- 可配置计算公式和商业规则
- 模板版本管理

#### 3. 历史记录
- 报价记录列表展示
- 按时间/楞型筛选
- 统计数据可视化
- 支持复制历史报价
- 报价详情查看

#### 4. 系统设置
- 纸板单价配置
- 损耗率/税率设置
- 数据导出/导入
- 数据备份与恢复

## 核心计算公式

### 外箱面积计算
\`\`\`
面积(㎡) = (长 + 宽 + 接头余量) × (宽 + 2×高 + 修边余量) / 10000
\`\`\`

### 成本计算链
\`\`\`
纸料成本 = 面积 × 纸板单价
损耗成本 = 纸料成本 × 损耗率
工艺成本 = 印刷费 + 特殊工艺费
小计成本 = 纸料成本 + 损耗成本 + 工艺成本
利润 = 小计成本 × 利润率
税费 = (小计成本 + 利润) × 税率
最终报价 = 小计成本 + 利润 + 税费
\`\`\`

### 客户等级利润率
- 普通客户: 15%
- 长期客户: 10%
- 大客户: 8%

### 楞型伸长系数
- A楞: 1.53
- B楞: 1.36
- C楞: 1.50
- E楞: 1.27
- AB楞: 2.08
- BC楞: 2.04

## 使用说明

### 创建报价
1. 点击底部"报价"标签
2. 输入客户名称和选择客户等级
3. 选择箱型模板
4. 输入纸箱尺寸、楞型、用纸配置
5. 配置工艺要求(可选)
6. 输入订单数量
7. 查看自动计算的报价结果
8. 点击"保存报价"按钮

### 管理模板
1. 点击底部"模板"标签
2. 查看现有模板列表
3. 点击"新建"按钮创建新模板
4. 或点击模板卡片上的编辑/删除按钮

### 查看历史
1. 点击底部"历史"标签
2. 查看报价记录列表
3. 使用筛选器按时间/楞型筛选
4. 点击记录查看详情
5. 可复制历史报价创建新报价

### 系统设置
1. 点击底部"我的"标签
2. 配置纸板单价、损耗率、税率
3. 导出/导入数据
4. 清除所有数据
